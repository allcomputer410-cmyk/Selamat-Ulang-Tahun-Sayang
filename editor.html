tersimpan otomatis di browser ini

Cara pakai

  1. Isi semua bagian di bawah. Pratinjau di samping akan ikut berubah.
  2. Pilih foto/video dari perangkatmu. Foto hanya dipakai untuk pratinjau, jadi nama file-nya yang dicatat.
  3. Klik Unduh config.js, lalu di GitHub ganti file js/config.js dengan file tadi.
  4. Upload foto ke assets/photos/ dan video ke assets/videos/ dengan nama file yang sama.
